# Часы в сообщениях ожидания

Сообщения ожидания проверки анкеты, категорий оценок, публикации и получения подтверждений начинаются с ⏳. При настроенном custom emoji используется Telegram MessageEntity, сохраняющий текст без HTML-преобразований. Ошибки и итоговые подтверждения не изменяются.

Для активации владелец входит в административный кабинет и отправляет боту отдельным сообщением выбранные премиум-часы ⏳ или ⌛ из панели эмодзи Telegram. У сообщения должен быть custom_emoji entity; копирования обычного символа недостаточно. Бот отправляет образец и сохраняет только ID и альтернативный символ в существующем VISITORS_KV, ключ cabinet_loading_emoji_v1. Клиенткам и неавторизованному владельцу менять настройку нельзя. Во время незавершённого административного ввода сообщение не перехватывается настройкой.

Для использования custom emoji Telegram требует Premium у фактического владельца бота либо другое предусмотренное API право. Premium у произвольного администратора не заменяет это условие. После явного отказа API 400 сообщение отправляется с обычным символом, без новой публикации или списания. При сетевом таймауте повторной отправки нет. Внешний вид анимации зависит от клиента Telegram и настроек воспроизведения.

Новых секретов, переменных, привязок или Worker не требуется. Исходные анкеты, резервы и балансы не меняются. Тесты используют фиктивные ID; настоящих публикаций и настройки живого emoji агентом нет. Активация остаётся действием владельца в Telegram.
