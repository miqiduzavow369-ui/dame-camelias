# Восстановление адреса анкеты

Новая ссылка с прежним суффиксом вида *.intimcity.gip распознаётся только для извлечения номера и подсказки: запрос на неподдерживаемый домен не выполняется. При технической ошибке проверки или работы с сохранённой анкетой бот предлагает открыть ту же анкету через действующий сайт и прислать полную ссылку. Текст осторожный: «Возможно, прежний домен устарел или сайт временно недоступен» — callback не позволяет отличить смену домена от всех сбоев прокси/входа/сайта.

Принимаются HTTPS-ссылки существующего разрешённого формата *.intimcity.rip/indi/anketa<ID>.htm без параметров/фрагмента, логина, порта или подмены номера. Другие суффиксы не становятся доверенными автоматически. Новый адрес проверяется отдельным read-only domain_probe; callback должен подтвердить тот же номер и точный URL с ожидаемым host.

До успешной проверки адрес сохранённой анкеты не меняется. Затем обновляются домен и URL только выбранной анкеты в текущем кабинете, домен её черновика оценок и ожидающего отзыва. Существующие кэшированные изображения копируются по новому ключу без удаления старых и без перезаписи существующей картинки. Тексты, выбор оценок, прежние подтверждения, кредитные claims/nonce, дневная дата, баланс и история расходов сохраняются.

Снимок остановленного шага хранится в персональном owner_anketa_domain_resume:<uid>:<profileId>. Можно выйти в начало и продолжить через кнопку «🔗 Обновить ссылку» в сохранённой карточке или прислав новую ссылку той же анкеты. Персональные поля не попадают в GitHub Actions inputs, кроме уже используемых ID/host/nonce. Завершённый контекст удаляется после запуска продолжения.

Продолжение использует новую корреляцию, сохранённый аккаунт и прежние данные. Чтение анкеты, услуг, аудит и проверка заполнения продолжаются в исходном режиме. Если публикация уже запускалась, повторный publish/review_publish запрещён: продолжается только proof/review_proof. Только полученный и доставленный подтверждающий скриншот может завершить прежнее кредитное списание, идемпотентно с прежним creditNonce. Старые callback исходной остановленной операции отклоняются. Новое размещение из сохранённой подготовки по-прежнему требует отдельной кнопки подтверждения.

Поздняя ошибка архивной операции не заменяет другую открытую анкету: приходит отдельная навигация восстановления. Существующая узкая legacy-процедура проверки отзыва сохранена для старых состояний; ввод новой ссылки и в ней теперь требует исходный номер анкеты.

Проверки без сети и настоящих публикаций: 98 JavaScript тестов и 23 Python теста. Новые сценарии включают старый суффикс, другую анкету/чужой host, все восемь стадий, запрет повторной отправки, сохранность реестра кредитов и подтверждений, возврат после выхода, поздний callback и неудачный probe. Живой переезд сайта агентом не проверялся.

Обновляется существующий Worker, привязки/переменные/секреты/webhook не меняются. Для отката к коду до изменения: main b321cb8aa862844595cdb6e47c30bbac08145081, Cloudflare version 33c33321-c056-47bb-8209-8354509cc920. Откат кода не восстанавливает данные; открытые процессы восстановления следует завершать совместимым исправлением.
