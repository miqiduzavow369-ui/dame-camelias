## Сохранить офлайн до потери доступа

1. Скачать независимый Git mirror: `git clone --mirror https://github.com/miqiduzavow369-ui/dame-camelias.git`. Хранить отдельно от Google; убедиться, что есть assets, src, tools, tests, workflows, wrangler.toml.
2. Создать резервного администратора репозитория/Cloudflare и проверить доступ. Архив не переносит права доступа.
3. Отдельно экспортировать **полные ключи и значения** namespace `VISITORS_KV` в зашифрованный архив (в нём чувствительные тексты и история). Для нового аккаунта пересоздать namespace и заменить её ID в wrangler.toml; текущий ID `a323fba4c8c84a7fb37e1e6a3a8264aa`.
4. Отдельно обеспечить восстановление состояния Durable Object `ORDER_REMINDERS` / `OrderReminder`; для новых deployment восстановить binding и миграцию `order-reminders-v1`. Простое скачивание Git не сохраняет текущие таймеры.
5. Секреты хранить только во внешнем менеджере паролей: GitHub Actions — `PROXY_HOST`, `PROXY_USERNAME`, `PROXY_PASSWORD`, `EXPECTED_EGRESS_IP`, `INTIMCITY_LOGIN`, `INTIMCITY_PASSWORD`, `ANKETA_CALLBACK_TOKEN`, `ANKETA_CALLBACK_URL`; Cloudflare Worker — `BOT_TOKEN`, `WEBHOOK_SECRET`, `DC_ACTIONS_TOKEN`, `ANKETA_CALLBACK_TOKEN`. Совпадающий callback token, URL вида `https://<worker>/api/anketa/result`. При переезде обновить webhook, репозиторий для GitHub dispatch и URL изображений.
6. Сохранить контроль BotFather над существующим ботом; нельзя заменить существующий бот без потери пользовательского контекста. Отдельно сохранить доступ к Intimcity (ЯН ПЕРВЫЙ) и, если нужно для управления заказами, ASHOO. Не предполагается, что ASHOO автоматизируется тем же скриптом.
