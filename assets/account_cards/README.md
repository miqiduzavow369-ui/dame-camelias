# Карточки аккаунтов DAME CAMELIAS

Эта папка хранит изображения для меню выбора аккаунтов Intimcity.

| Аккаунт | Файл |
| --- | --- |
| 👨‍💻 Ян Первый | `yan_first.jpg` |
| 🔒 Ян Второй (после подключения) | `yan_second.jpg` |

Для нового аккаунта: добавьте фотографию JPG по уникальному имени из латинских букв, цифр и подчёркиваний; затем зарегистрируйте её в `ACCOUNT_CARD_FILES` в `src/owner_anketa.js`.

Рекомендуемый формат: горизонтальная карточка около 1889 × 832 пикселей, JPG, размер до 5 МБ. Используйте только свои утверждённые изображения; не размещайте пароли и персональные настройки прокси.

При выборе аккаунта бот показывает изображение вместе с меню его действий. Если изображение недоступно, отображается обычное текстовое меню, не ломая остальные функции.
