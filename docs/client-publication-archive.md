# Архив публикаций в карточке клиентки

Владелец: 👑 Администратор → 👥 Клиентки → карточка → 📚 Публикации.
Далее отображаются непустые даты по Москве, аккаунты публикации и сохранённые Telegram-подтверждения оценок/отзывов. Даты идут от новых к старым; есть возврат и переход в начало. Скриншоты выводятся по восемь, временные административные копии удаляются при уходе; оригиналы у клиентки сохраняются.

Перед текстом карточки показывается существующее изображение первой анкеты с подтверждённым действием, если доступно. При отсутствии изображения текст и управление остаются доступны.

Архив читается из персональных записей Durable Object с резервным чтением прежних ключей KV. Tombstone/актуальная запись DO имеет приоритет. Подтверждённые статусы без файла не превращаются в вымышленные скриншоты. Удаление анкеты из личного списка не удаляет архив. Просмотр доступен владельцу после авторизации, включая клиенток с нулевым балансом или приостановленным доступом.

Изменение не запускает публикации, проверки сайта, списания или миграции и не меняет существующие записи архивов/балансов. Новых привязок, секретов, переменных и Worker не требуется.

Проверки: 89 JavaScript и 23 Python теста, синтаксис всех Worker-модулей. Архивные тесты проверяют изоляцию, авторизацию, границу московских суток, отсутствие пустых разделов, пагинацию, старые KV-записи, приоритет DO и отсутствие изменений исходных данных. Реальные публикации в проверках не выполняются.

Откат: вернуть предыдущую версию кода Worker (main до изменения: 97ad031113e7ff42649bfe37d69152d27af224e1; Cloudflare version dc1f533b-b11f-4d24-96b8-e4f7bc35b496). Изменений формата данных нет. Откат кода не является восстановлением данных из резервной копии.
