# Соглашение DAME CAMELIAS

В главном меню для всех пользователей личного чата есть «📜 Соглашение». Шесть последовательных экранов содержат дословные тексты владельца, только с оформлением заголовков и абзацев. На первых пяти — «✅ Согласна» / «❌ Не согласна», на шестом — «✅ Принимаю соглашение» / «❌ Не согласна». Одно сообщение редактируется между шагами; после отказа или итогового принятия удаляется и появляется главное меню.

Финальное принятие возможно только после пяти предыдущих подтверждений; проверяются приватная идентичность, собственный chat ID, flow token, шаг и ID сообщения. Состояние хранится в существующем классе OrderReminder под отдельным именем agreement:v1:<uid>. Создание клиентского аккаунта или наличие баланса для чтения/принятия не требуется. Принимается полная копия редакции 2026-10-15-v1 с ID, timestamp и шестью текстами. Эта копия не заменяется будущим чтением или последующим отказом при повторном просмотре. Первый отказ без принятия сохраняет declinedAt.

Статус только информационный. Кабинет, доступ, баланс, резервы, публикации и создание клиентки не блокируются соглашением. Владелец видит три состояния: «✅ Соглашение подписано», «❌ Отказалась от соглашения», «➖ Соглашение ещё не принято»; ошибка чтения показывается отдельно. Статус виден в карточке, после ввода нового ID и перед подтверждением создания аккаунта.

После принятия и выдачи доступа в кабинете под «➕ Ввести новую анкету» появляется «📜 Подписанное соглашение». При нулевом балансе чтение также доступно. Копия показывает все шесть сохранённых текстов, «Подписан ID» и дату/время согласия по Москве; кнопка «🌹 Вернуться к анкетам» очищает копию и открывает кабинет. Публичный callback не позволяет выбрать чужой ID. Если доступа больше нет, возврат ведёт в главное меню.

Новых Worker, ботов, секретов, переменных, bindings, migrations или webhook нет. Публичные тексты находятся в коде, реальные сведения о принятии — только в Cloudflare DO, не в репозитории. Соглашение не изменяет фактическую реализацию лимитов или модерации; добавлен только информационный интерфейс по тексту владельца.

Проверки: 113 JavaScript тестов и 23 Python теста. Контрактные тесты сверяют дословные формулировки, включая «за оставшийся оплаченное количество публикации». Проверяются защита от пропуска шагов/чужой идентичности, один экран без мусора, неизменность принятой копии и даты, принятие до регистрации, статус перед выдачей доступа, отсутствие влияния отказа на кабинет и наличие копии при нуле. Сквозной webhook-тест проходит шесть шагов без создания клиента или кредитного объекта. Реальных сообщений или подписей агент не создавал.

Предыдущий main 503923cda6ec439ab7c2fa33d755c6bea80eef0f, Worker version 066313f6-43ca-4765-901b-8d84e5e8cb47. Откат кода скроет интерфейс, но не удалит новые записи agreement:v1:<uid>. Для полноценного сохранения данных нужны отдельные резервные копии Cloudflare; эта задача их не создаёт.
