# Модерация отзывов в группе

Группа: -1003900552612. Единственный модератор: Telegram ID 5866034656. Только отзывы; маршрут оценок не меняется.

После прежнего подтверждения клиенткой сервер сохраняет неизменяемый исходный снимок в её кабинете и создаёт заявку. На сайте ничего не отправляется, кредитный и дневной резерв ещё не создаются. Клиентка видит прежний экран ожидания с часами. В группе — ID, Telegram username (либо отсутствие ника), номер анкеты, аккаунт публикации «Ян Первый», полный текст и кнопки «✅ Опубликовать», «✏️ Корректировать», «❌ Отменить».

Корректировка доступна только владельцу в указанной группе: нажать кнопку и ответить боту полным новым текстом (10–3000 символов). Карточка обновится; отправки нет до отдельного одобрения. Старая версия кнопок недействительна. Замена текста сохраняет предыдущее содержимое в приватной истории заявки. Клиентке внутренние сообщения группы не пересылаются.

При одобрении сервер повторно проверяет флаги, доступ клиентки, сохранённую анкету, общий дневной лимит и баланс. Кредитный резерв и постоянная защита от повтора создаются перед dispatch. Один ticket может запустить его только один раз; результат транспортного таймаута не запускает автоматический повтор. Исправленный текст попадает в приватный payload и последующую проверку сайта, а не в workflow inputs/логи.

Отмена до одобрения не создаёт расходов, сохраняет клиентский черновик и сообщает клиентке, что отзыв не отправлен. Кнопки закрываются. Удаляется только связанное сообщение ожидания. Отмена после принятого запуска недоступна. Уведомление отмены при внутреннем сбое повторяется идемпотентно через alarm.

После доставленного клиентке скриншота и фиксации результата заявка становится published. Отдельное сообщение в группе содержит ссылку на исходную карточку (https://t.me/c/3900552612/<messageId>). При сетевой неоднозначности отправки группового уведомления повторный отчёт автоматически не создаётся; статус и факт попытки сохраняются, публикация не повторяется. При недоступности внутренней очереди уведомление клиента о результате сохраняется, уведомление группы ставится в durable outbox.

Реализация использует существующий ORDER_REMINDERS и новые изолированные имена объектов review-moderation:v1:<uid>:<ticket>, review-moderation-index:v1. Внешнего маршрута для создания решений нет. Идентичность модератора, группа, ID сообщения, версия и состояние заявки проверяются сервером. Индекс ответов группы не содержит текстов, только связь ID сообщения с заявкой. Новых Worker, ботов, ключей, переменных, привязок, migrations и webhook нет.

Уже запущенные до установки операции продолжают принимать прежние callbacks; новые отзывы требуют модерации. Восстановление домена и ручная проверка результата сохраняют moderationTicket и не отправляют отзыв повторно.

Проверки: 105 JS и 23 Python теста, синтаксис и импорт Worker. Сквозной тест моделирует передачу в группу без резервов, запрет чужого решения, исправление, устаревшие кнопки, однократную отправку, доставку скриншота клиентке, списание ровно одного кредита и один отчёт со ссылкой. Отдельно проверены отмена и сохранность черновика/баланса. Настоящие отзывы не отправлялись; фактическая доступность группы подтвердится первой заявкой, поскольку прямого доступа к bot token агент не имеет.

Откат к прежнему коду вернёт прямую отправку новых отзывов и не обработает очередь модерации. Для аварийной остановки сначала выключить новые публикации; не выполнять слепой откат с открытыми заявками. Запущенные отправки не повторять; callbacks сохранять. Резервная копия живых данных этой задачей не создавалась.
