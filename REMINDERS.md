# DAME CAMELIAS — автоматические напоминания

Расширение существующего Cloudflare Worker и @DameCameliasConsultantBot. Новый бот и изменение Telegram webhook не нужны.

## Поведение

- Открытие «Заказ» или быстрого заказа включает таймер.
- Каждое последующее действие в личном чате или HTML-анкете откладывает напоминание на 2 часа.
- Одно напоминание на пользователя. После успешной подачи заявки через любой из двух способов таймер отменяется. Повторное открытие заказа не включает повторное напоминание.
- Кнопки «Стоимость», «Сроки», «Нужна помощь» и свободный текст передаются сразу в существующий чат отчётов 5866034656.
- После перехода в другой раздел обычный текст перестаёт считаться ответом на напоминание. Ответ через Telegram «Ответить» на само напоминание по-прежнему распознаётся. Ответы на вопросы быстрого заказа имеют приоритет.
- При сбое отправки отчёта выполняется до пяти повторных попыток с интервалом в минуту.

## Развёртывание

Используются существующие BOT_TOKEN, WEBHOOK_SECRET и VISITORS_KV. Добавлены ORDER_REMINDERS и SQLite Durable Object OrderReminder с миграцией order-reminders-v1 в wrangler.toml. Нужен успешный deploy обновлённой main в существующий Worker dame-camelias.

Durable Object хранит состояние и запускает alarm через два часа, независимо от расписания отчётов посетителей.

Проверка: node --test tests/reminders.test.mjs

## Ограничения и проверка запуска

Напоминания начинают учитываться с первого нового действия после развёртывания; старые посетители не импортируются. Действия в анкете учитываются при подписанной Telegram initData не старше суток; существующая проверка отправки заказа ограничена 10 минутами. Произвольную активность вне бота Telegram не передаёт.

Telegram не поддерживает idempotency key для sendMessage. Попытка отправки напоминания сохраняется до сетевого вызова: при неопределённом сетевом сбое повторной отправки клиенту нет, чтобы избежать двойного сообщения. Возможна потеря напоминания при таком сбое. При неопределённом результате отправки отчёта его повторная доставка может дать дубликат.

После deploy проверить на тестовом клиенте: открытие «Заказ», перенос таймера, отмену после обеих форм заявки, получение напоминания и ответы обоими способами. Живое выполнение нельзя подтвердить только тестами с имитацией Telegram.

Паспорт проекта не приложен к текущему чату; инструмент истории вернул «Personal context is disabled». Правила реализованы по доступному фрагменту обсуждения. Текст напоминания и названия кнопок восстановлены по этому фрагменту, а не сверены с полным паспортом.
