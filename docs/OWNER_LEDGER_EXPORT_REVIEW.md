## Конкретное изменение для согласования

- В существующем Worker добавить GET /api/admin/ledger-backup, доступный только с существующим ANKETA_CALLBACK_TOKEN в заголовке Authorization: Bearer. Без CORS; ответы no-store. Секрет в URL не принимается.
- Экспорт разрешён только до 16 октября 2026 13:30 МСК; затем 410. После скачивания рекомендуется удалить временное изменение отдельно согласованной выкладкой.
- Цель фиксирована: объект publication-credits:5866034656, ключ credits_v1. Пользователь не может выбрать другой объект через параметры.
- В DO добавлена отдельная ветка до старого обработчика: единственная операция с хранилищем — get существующего ключа. Нет seed, put, delete, изменения alarm, claims или списаний; нет запросов в Telegram, GitHub или сайт.
- Экспорт включает точную JSON-запись: grant, spent, claims/резервы, history и прочие сохранённые поля. Действующий код хранит только последние 500 элементов history; экспорт не восстановит более старую отсутствующую историю.
- Существующий callback-секрет получает дополнительную возможность чтения кредитной записи владельца. Не передавать его в чат, URL, публичный репозиторий или логи. Новых ключей не создаётся. Если сохранённого существующего секрета у владельца нет, выгрузка этим способом останется заблокирована — значения зашифрованных переменных Cloudflare не доступны для чтения.

## Выгрузка после отдельного разрешения на установку

1. Перепроверить, что production main и активная версия не изменились. Если изменились — пересобрать патч поверх фактической версии и повторить тесты. Не выкладывать старую основу поверх неизвестной новой версии.
2. Владелец отдельно разрешает временное изменение существующего Worker именно для резервирования. Сохранить полный предыдущий version ID, все настройки, секреты и bindings. Не объединять PR №106. Не менять webhook или флаги кабинетов.
3. После установки запустить на компьютере владельца Python 3: tools/download_admin_ledger.py. Адрес существующего Worker и уже имеющийся ANKETA_CALLBACK_TOKEN вводятся локально; секрет скрыт при вводе. Скрипт не запрашивает Cloudflare API token.
4. Скрипт проверяет формат и ID, сохраняет JSON в новую папку с правами 0700, файлы 0600, рассчитывает SHA256 и повторно проверяет записанные байты. Старые файлы не перезаписываются. Это ограничение доступа к файлам, не шифрование; держать копию на защищённом устройстве, вне общих папок и публичного GitHub.
5. Повторно скачать запись при отсутствии новых публикационных операций и сравнить value. capturedAt меняется; сравнивать содержимое записи, а не контрольные суммы двух разных ответов. Любое расхождение требует сверки, а не перезаписи хранилища.
