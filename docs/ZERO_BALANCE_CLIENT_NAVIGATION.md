# Клиентский кабинет при израсходованном балансе

После последней подтверждённой публикации следующие клиентские кнопки ведут к своему списку анкет. Кнопки этого списка при нуле показывают сообщение об исчерпанном лимите, сохранности данных, пополнении через администратора и ссылку https://t.me/DameCamelias. Добавление, удаление анкет, подготовка новых публикаций и старые формы оценок при полностью израсходованном балансе закрыты.

Ограничение действует для авторизованных активных клиентов при available=0 и reserved=0. Нулевой доступный остаток из-за незавершённого резерва не считается окончательным исчерпанием. Входящие результаты, подтверждения и settlement не проходят через эту навигационную блокировку: последняя операция может завершиться и отправить постоянное подтверждение. Полученные подтверждения из чата не удаляются.

Администратор сохраняет управление клиентами и пополнением. На каждом новом клиентском действии проверяется реальный кредитный объект; положительное пополнение автоматически восстанавливает обычную навигацию, включая ранее выданные кнопки нулевого баланса. Балансы, расходы, история, резервы и сохранённые анкеты не сбрасываются.

В карточке публикационного аккаунта включён HTML parse_mode как для подписи фотографии, так и для текстового варианта. Это исправляет буквальные теги <b> на экране. При выполненных оценке и отзыве подпись предлагает посмотреть подтверждения вместо выбора нового действия.

Проверено: 77 JS и 23 Python теста, синтаксис и импорт Worker. Добавлены сценарии нулевой навигации и изоляции, восстановления после пополнения без сброса истории, последнего резерва, запрета устаревшей формы, сохранения управления владельца, HTML фото/текст. Сценарий последнего кредита использует реальный обработчик имитированного proof callback, проверяет однократное списание и сохранение квитанции. Сетевые сервисы и хранилища в тестах имитируются; настоящих публикаций ради проверки не выполняется.

Перед этой задачей владелец сообщил об успешных реальных оценке и отзыве с уменьшением клиентского баланса до нуля. Это подтверждение владельца, не независимое чтение агентом реестра сайта или Cloudflare. Изменение не добавляет миграций, переменных, секретов или новых Worker и сохраняет текущие включённые флаги.
