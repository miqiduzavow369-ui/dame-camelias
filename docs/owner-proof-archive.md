# Архив подтверждений оценок

Подтверждающие фотографии не хранятся в публичном GitHub: в них могут быть данные личного кабинета.

После успешной проверки сайта и отправки фото Telegram хранит оригинал изображения. Бот сохраняет `file_id` отправленного фото и дату в Cloudflare KV (без TTL).

**Ключ:** `owner_anketa_proof_archive_v1:<account>:<profile_id>`.

Значения: `account`, `profileId`, `fileId`, `date`, `savedAt`.

**Обычный повторный запрос:** отправка по Telegram `file_id` — без нового запуска GitHub Actions и браузера. Если `file_id` больше не работает или архив ещё пуст, выполняется read-only проверка в «Проверенные».

**Безопасность:** оценка и отзыв — разные типы публикаций. Наличие архивного фото оценки не даёт разрешения выставлять оценку повторно. Удаление сохранённой анкеты не стирает архив публикаций и блокировку.

**Историческая Lady Fox №652282:** первый запрос после внедрения этого архива ещё раз прочитает раздел «Проверенные» и сохранит Telegram `file_id`. Далее запросы будут быстрыми.

**Навигация:** итоговое фото имеет кнопки для возвращения к анкете, списку анкет и в начало.
